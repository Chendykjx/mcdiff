麦门考古博物馆

every gone SKU gets a tombstone

它是怎么做的

MCP → commit → diff
01

麦当劳中国 MCP 采集

调官方 MCP server 的门店与菜单工具，拿到当前在售餐品、价格、标签与分类。

  • query-meals
  • calculate-price
  • query-store-coupons
  • query-promotions
  • query-nearby-stores
  • now-time-info
02

快照 = 一次 commit

整份菜单按 code 排序后算 sha256 校验和；校验和不变就不产生新 commit。每天一次，历史自然可回溯。

  • sha256 checksum
  • daypart · 午餐/深夜
  • synthetic 标记
03

diff + 博物馆

新旧快照逐 SKU 比较，输出新上/下架/涨价/降价/改名/标签/换分类；下架的 SKU 进博物馆立碑。

  • + added
  • - removed
  • ~ price / tags
  • tombstone
采一次 $ python -m mcdiff capture --store 1420576
